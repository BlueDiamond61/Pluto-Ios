# NOVA

**Website:** https://bluediamond61.github.io/Pluto-Ios/

NOVA is a focused, purple-themed workspace concept for organizing and editing Lua source text.

## GitHub Pages

If deployment reports that Pages is not configured:

1. Open [Repository Settings → Pages](https://github.com/BlueDiamond61/Pluto-Ios/settings/pages).
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Open the [Actions tab](https://github.com/BlueDiamond61/Pluto-Ios/actions) and rerun the failed **Deploy NOVA website to GitHub Pages** workflow.

After deployment succeeds, visit the website link above.

## About

The web preview is a local source-text editor and project organizer. It does not execute code, inject into games, or bypass platform protections.
